# Uso de asistentes de IA en este proyecto

La consigna (sección 8) permite usar asistentes de IA y aclara que el equipo tiene que poder comprender, justificar y modificar el código que incorpora. Esta carpeta registra cómo se usaron.

## Cómo trabajamos

- El asistente (Claude Code) genera estructura y código a partir del informe de la Etapa 1 y de un plan de implementación que el equipo revisó y corrigió antes de empezar.
- Ningún cambio entra al repositorio sin que un integrante lo pruebe a mano, lo entienda y lo commitee con su propio nombre. El asistente no hace commits.
- Parte del código lo escriben los integrantes directamente (dominio, repositorio con Room, cliente Retrofit, pantalla de Estado); el asistente arma la estructura y revisa.
- Cada pull request responde, para cada clase importante, las seis preguntas de la consigna: qué problema resuelve, qué capa modifica, qué dependencias agrega, si hay una alternativa más simple, cómo se comprueba y qué pasa si falla.
